- **渐进加载**：信仰告白第 3 章起、大/小要理每 8 问、背诵版每 10 问、信经与联合信条的折叠条目都放在 `<template>` 里，接近视口（提前 1600px）时在每帧 8 ms 预算内分批挂载；折叠框在第一次展开时挂载；锚点链接、目录跳转、页内搜索会先挂载目标内容。
- **去掉 Lenis**，改用浏览器原生滚动；去掉顶栏 `backdrop-filter`、背景漂浮动画、亮度 / 模糊滤镜和 box-shadow 过渡（背诵版「遮盖答案」也从模糊滤镜改为透明文字 + 横纹底）。
- **阅读进度条与悬浮钮进度环**在支持的浏览器上改用 CSS 滚动时间线（`animation-timeline: scroll()`），滚动时不再运行 JS。
- 选项卡、记忆标记改为事件委托；图片改为 WebP（`decoding="async"` + `width/height` + `srcset/sizes`）；站内链接用 Speculation Rules 预渲染（conservative：按下时开始）与悬停预取（moderate），配合跨页 View Transitions。本站使用系统字体，没有网络字体，因此 `font-display` 不适用。
