    🧠 「前90信、后106行」大要理问答以第90问为分水岭：1–90 当信什么（神 → 人 → 约 → 基督 → 恩典中 → 荣耀中），91–196 当尽何本分（律法 → 十诫 → 罪与出路 → 蒙恩之道）。口诀：「神人约主，恩荣两交；律诫罪道，祷告收尾」。
    📏 十诫解释八规则（WLC 99，概括）
    1. 完全：律法要求全人完全的顺服。
    2. 属灵：管到悟性、意志、情感与心灵。
    3. 互见：同一件事可在几条诫命中从不同角度被要求或禁止。
    4. 正反：吩咐一项本分，就禁止相反的罪；禁止一项罪，就吩咐相反的本分。
    5. 时机：所禁止的任何时候都不可行；所吩咐的总是本分，但不是每项本分时时都要做。
    6. 同类：一项罪或本分之下，同类的一切连同其原因、手段、机会都包括在内。
    7. 推己：自己当守的，也要按身份帮助别人守。
    8. 助人：别人当守的，我们要按身份与呼召帮助他们。
    口诀：「全灵互反，时类己人」。逐字原文见 大要理第99问。
